Domain-Specific AI Research Assistant with Knowledge Graph

A research assistant that ingests academic PDFs and answers questions using hybrid RAG. Combines ChromaDB dense retrieval with BM25 sparse retrieval through Reciprocal Rank Fusion, checks generated claims using an NLI cross-encoder, and builds an interactive multi-paper knowledge graph across models, datasets, and metrics.

SignBridge — Real-Time ISL Translator with Edge Deployment

Indian Sign Language recognition system for all 26 ISL alphabet signs. Uses a sliding 30-frame CNN–LSTM model with multi-head attention and MediaPipe hand landmarks. Reports 99.74% validation accuracy, 22-minute CPU training, and 353 FPS with ONNX FP32 deployment.
